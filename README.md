# FDE Journey

Transitioning from Data Engineer to AI Systems Engineer, targeting senior IC roles at top-tier AI organizations.

**Background:** 6 years in software, 3 as a Data Engineer at AB-InBev (ADF, Databricks, PySpark, SQL, Python). Starting focused AI/LLM learning on Oct 14, 2026.

**Target:** AI Engineer / Applied AI roles at companies like Google, Anthropic, OpenAI, Databricks, Snowflake. L4-L5 bar.

**Timeline:** ~12-18 months of structured prep, applying once US work authorization lands.

## Approach

Three parallel threads, every week:
1. **Build an AI system** — one shippable thing weekly
2. **Learn one systems concept deeply** — DDIA + hands-on
3. **System design practice** — one written design per week
4. **DSA practice** — pattern-based, 4 days/week

Everything I build has a "Why" writeup: what tradeoffs, what alternatives considered, what I'd change.
